\chapter*{Abstract}
This report presents the installation, configuration, and testing of a Windows Server 2019 environment developed to meet the network and security requirements of CPUT. The project was implemented using the hypervisor utilised during Semester~1 and included the deployment of several key server roles and services.

The implementation involved configuring Active Directory Domain Services (AD DS) for centralized user and resource management, Domain Name System (DNS) for name resolution, and Dynamic Host Configuration Protocol (DHCP) for automatic IP address allocation. In addition, Group Policy settings were applied to improve the security of the environment by restricting Command Prompt access, disabling removable storage devices, preventing unauthorized software installations, and enforcing stronger password policies.

Remote Access Services and Windows Certificate Services were also configured to provide secure connectivity and authentication within the network environment. Each service was tested to verify that it functioned correctly and met the specified requirements. Screenshots of all installation, configuration, and testing procedures were captured and included as evidence of successful implementation.

The results demonstrate how Windows Server 2019 can be used to create a secure and manageable network infrastructure that supports organisational requirements while following recommended security practices.
